## 🎯 1. В чем главная идея MiniMind?

Обучение промышленных LLM (Llama, DeepSeek, GPT) требует миллионов долларов и тысяч видеокарт H100. Это создает иллюзию, что понять претрейн и файнтюнинг на практике обычному инженеру невозможно.

**MiniMind** доказывает обратное: проект предлагает ультралегковесную языковую модель размером всего **64 миллиона параметров** (примерно 1/2700 от объема GPT-3), которую можно **полностью обучить с нуля за 2 часа на обычном ноутбуке или домашнем ПК**.

## 🗺 2. Полный цикл обучения (Training Lifecycle)

```text
[ Сырой текстовый корпус (News, Wikipedia, QA) ]
                       │
                       ▼
┌────────────────────────────────────────────────────────┐
│ ЭТАП 1: Pre-training (Предварительное обучение)        │
│ • Архитектура: Decoder-only Transformer                │
│ • Кастомный BPE-токенизатор                            │
│ • Обучение языковому предсказанию токенов              │
└────────────────────────┬───────────────────────────────┘
                         │
                         ▼
┌────────────────────────────────────────────────────────┐
│ ЭТАП 2: Supervised Fine-Tuning (SFT)                   │
│ • Обучение следовать инструкциям в диалоге             │
│ • Шаблоны промптов: User / Assistant                   │
└────────────────────────┬───────────────────────────────┘
                         │
                         ▼
┌────────────────────────────────────────────────────────┐
│ ЭТАП 3: LoRA & DPO (Выравнивание и предпочтения)       │
│ • Direct Preference Optimization (DPO)                 │
│ • Дообучение через Low-Rank Adaptation (LoRA)          │
└────────────────────────────────────────────────────────┘
```

## 📂 3. Структура проекта

* `model/LMConfig.py` — конфигурация гиперпараметров модели (число слоев, размерность скрытого состояния, головы внимания).
* `model/model.py` — чистая и понятная реализация трансформера на PyTorch (Attention, RoPE, RMSNorm).
* `1-pretrain.py` — скрипт предварительного обучения на неразмеченном тексте.
* `2-full_sft.py` — скрипт дообучения на диалоговых данных.
* `3-dpo_train.py` — обучение с подкреплением через алгоритм DPO.
* `eval_model.py` — интерактивный чат с вашей собственной обученной моделью в терминале.

## 🚀 4. Как запустить локально?

```bash
# 1. Клонирование репозитория
git clone https://github.com/jingyaogong/minimind.git
cd minimind

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Запуск обучения (займет ~2 часа на RTX 3090)
python 1-pretrain.py
python 2-full_sft.py

# 4. Общение со своей моделью
python eval_model.py
```
