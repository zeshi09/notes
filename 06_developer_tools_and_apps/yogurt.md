## 🎯 1. В чём ценность: Приватная альтернатива Granola и облачным ботам

Облачные AI-секретари для встреч (Otter, Fireflies, Fathom) либо подсаживают раздражающего бота в Zoom/Meet, либо отправляют аудио и транскрипты на сторонние серверы. **Yogurt** делает всё локально на компьютере пользователя, бесплатно и под лицензией MIT:

1. **Никаких ботов в созвоне:** записывает напрямую поток с микрофона и системный вывод звука (поддерживает авто-предложение записи при детекте звонка по микрофону, вкладке браузера или ближайшему событию календаря и автоматическую остановку по завершении звонка).
2. **100% локальный AI-конвейер:**
   * **Транскрибация (99 языков):** `whisper.cpp` (до `large-v3-turbo`, в зависимости от железа); на поддерживаемых Mac для мгновенных субтитров используется нативный Apple `SpeechAnalyzer`, а финальный сохранённый транскрипт формирует Whisper.
   * **Саммари и Q&A с источниками:** локальные open-weight модели из семейств **Gemma 4**, **gpt-oss** или **Qwen3** поверх `llama.cpp` (первоначальная загрузка: ~5 GB лёгкая модель + от 14 GB оптимальная модель под ресурсы ПК; затем работает полностью офлайн).
3. **Идентификация спикеров и календарь (macOS):** через права Accessibility Yogurt считывает имена говорящих напрямую из UI Zoom, Teams и Google Meet, а локальный календарь подключается без облачной OAuth-авторизации.

## 🔌 2. Локальный read-only MCP-сервер для AI-ассистентов

Одно из самых практичных решений в Yogurt — встроенный **локальный MCP-сервер** (отключён по умолчанию в **Settings → AI apps**), позволяющий вашему кодинг-агенту или десктопному ассистенту читать историю встреч, заметки и транскрипты:

| Аспект | Реализация в Yogurt |
| :--- | :--- |
| **Права доступа** | Строго **read-only** (чтение встреч, заметок и транскриптов без права изменения) |
| **Транспорт (macOS / Linux)** | Локальный Unix-сокет в каталоге профиля с правами **`0600`** (доступ только у текущего пользователя ОС) |
| **Транспорт (Windows)** | Named pipe со случайным именем на каждый запуск, хранящимся в папке профиля |
| **Экспорт** | Копирование и сохранение заметок/транскриптов в Markdown |

> **Модель угроз MCP:** в документации честно отмечено, что хотя сам сокет защищён правами `0600` (без отдельного per-app токена), любой сторонний ассистент, которому вы подключили MCP, может отправлять прочитанные выдержки из заметок в свою облачную LLM.

## 💻 3. Системные требования и хранение данных

* **Платформы:** macOS 14.4+ (Apple Silicon), Windows 10 (2004+) x64, Linux x64 (AppImage, Ubuntu 22.04+); минимум **8 GB RAM**.
* **Локальное хранилище:**
  * macOS: `~/Library/Application Support/Yogurt`
  * Windows: `%APPDATA%\Yogurt`
  * Linux: `~/.config/Yogurt` (или `$XDG_CONFIG_HOME/Yogurt`)

## 💡 4. Главные инженерные выводы

1. **Связка `whisper.cpp` + `llama.cpp` + MCP** превращает записи созвонов из «мёртвого архива» в живой локальный источник контекста для персональных и кодинг-агентов.
2. **Гибрид Apple `SpeechAnalyzer` + Whisper на macOS** — умный инженерный трюк: системный движок даёт нулевую задержку в реальном времени, а Whisper гарантирует качественный сохранённый текст на 99 языках.
3. **Локальный IPC через `0600` Unix-сокет / ephemeral named pipe** вместо открытого localhost-порта избавляет от целого класса CSRF/DNS-rebinding атак на локальный MCP-сервер.
