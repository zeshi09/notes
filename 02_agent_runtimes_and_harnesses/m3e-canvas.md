## 🎯 1. В чем идея и зачем это нужно?

При «вайб-кодинге» (*Vibe Coding*) с помощью AI-агентов (Claude Code, Cursor, Codex, v0) разработчик часто сталкивается с проблемой:  
> Текстом сложно передать точное взаимное расположение кнопок, карточек, списков и навигации. В итоге агент генерирует интерфейс «на свое усмотрение», и приходится тратить десятки итераций на подгонку верстки.

**M3E Canvas** решает эту проблему за 2 минуты:
1. Вы открываете легкий холст в браузере.
2. Быстро перетаскиваете и связываете экраны из готовых компонентов **Google Material 3 Expressive** (FAB, TopAppBar, NavigationBar, Cards, Chips, Lists).
3. Прокликиваете прототип прямо в браузере.
4. Нажимаете **«Copy Prompt»** — и получаете идеальный структурированный промпт для кодинг-агента с точной иерархией элементов, цветовыми ролями и переходами.

```text
┌────────────────────────┐
│  M3E Canvas в браузере │ ──► Быстрый набросок экранов за 2 минуты
└───────────┬────────────┘
            │
            ▼
┌────────────────────────┐
│  Кнопка "Copy Prompt"  │ ──► Генерирует исчерпывающее структурированное ТЗ:
└───────────┬────────────┘     [Цветовые роли, шрифты, отступы, состояние компонентов]
            │
            ▼
┌────────────────────────┐
│   AI Кодинг-Агент      │ ──► С первого промпта пишет чистый компонентный код
│ (Claude Code / Cursor) │     на React + Tailwind без дефектов и угадываний
└────────────────────────┘
```

## 💎 2. Ключевые фичи

1. **Стандарт Google Material 3 Expressive:** Поддерживает обновленный визуальный язык Material с выразительными скруглениями, динамическими цветовыми контейнерами (*Primary Container*, *Surface Tint*) и тактильными акцентами.
2. **Интерактивные связи (Clickable Prototype):** Можно соединять экраны стрелками и проверять пользовательские сценарии кликом прямо на холсте.
3. **Zero Backend (100% приватность):** Работает полностью в браузере на базе `localStorage`. Никаких баз данных, аккаунтов и передачи ваших идей на чужие серверы.
4. **Оптимизировано под LLM:** Сгенерированный промпт отформатирован в виде четкой спецификации компонентов с указанием props, стилей и обработчиков событий.
