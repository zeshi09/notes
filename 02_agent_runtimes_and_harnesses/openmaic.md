## 🎯 1. Введение и концепция

**OpenMAIC** (*Open Multi-Agent Interactive Classroom*) — это передовая открытая образовательная платформа, моделирующая полноценную интерактивную учебную аудиторию с помощью роя специализированных AI-агентов.

Вместо привычного формата «один пользователь общается с одним чат-ботом», OpenMAIC разворачивает **многопользовательскую ролевую экосистему**, в которой пользователь погружается в живую дискуссию:

```text
                        ┌────────────────────────┐
                        │   Студент (Человек)    │
                        └───────────┬────────────┘
                                    │ (вопросы, гипотезы, ответы)
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                    OPENMAIC VIRTUAL CLASSROOM                          │
│                                                                        │
│  ┌─────────────────────────┐             ┌─────────────────────────┐  │
│  │   Professor Agent       │             │   Skeptical Peer Agent  │  │
│  │   (Ведущий лектор:      │◄───────────►│   (Студент-оппонент:    │  │
│  │    структура, концепты) │             │    критика, контрпримеры│  │
│  └────────────┬────────────┘             └────────────┬────────────┘  │
│               │                                       │               │
│               ▼                                       ▼               │
│  ┌─────────────────────────┐             ┌─────────────────────────┐  │
│  │   Teaching Assistant    │             │   Curator & Scribe      │  │
│  │   (Тьютор: подсказки,   │◄───────────►│   (Секретарь: майндмапы,│  │
│  │    персональные аналогии│             │    конспекты, таймлайны)│  │
│  └─────────────────────────┘             └─────────────────────────┘  │
└────────────────────────────────────────────────────────────────────────┘
```

## 💎 2. Ключевые возможности

1. **Иммерсивный многоагентный диалог (Multi-Agent Debate):**
   * Агенты не просто отвечают по очереди — они спорят друг с другом, приводят альтернативные научные точки зрения, задают наводящие вопросы пользователю и разбирают парадоксы.
2. **Динамическая адаптация сложности (Cognitive Load Balancing):**
   * Тьютор отслеживает понимание студента: если тема дается тяжело, ассистент перехватывает инициативу и приводит наглядные бытовые аналогии; если студент отвечает легко — оппонент усложняет граничные условия задачи.
3. **Генерация визуальных артефактов на лету:**
   * В процессе лекции агент-секретарь автоматически строит интерактивные майндмапы, формулы LaTeX, блок-схемы и итоговый конспект урока.
4. **Голосовое общение в реальном времени (WebRTC / Fast Voice):**
   * Поддержка живой голосовой дискуссии с минимальной задержкой (low-latency audio stream) с эмоциональной дифференциацией голосов разных агентов.

## 🚀 3. Быстрый запуск

```bash
# Клонирование репозитория
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC

# Установка зависимостей
npm install
cd backend && pip install -r requirements.txt

# Запуск
npm run dev
```
