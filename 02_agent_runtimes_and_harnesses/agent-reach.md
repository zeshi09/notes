## 🎯 1. Проблема: Почему AI-агенты «слепы» в современном интернете?

Автономные кодинг-агенты демонстрируют выдающиеся результаты при работе с локальными файлами и репозиториями, но мгновенно теряют эффективность, когда им требуется собрать актуальную информацию из глобальной сети:
* **Заградительные тарифы на API:** Официальный доступ к Twitter API стоит от $100 до $5000 в месяц. Reddit заблокировал открытые неаутентифицированные эндпоинты (серверные IP получают HTTP 403).
* **Пейволлы и авторизационные стены:** Сервисы вроде XiaoHongShu, LinkedIn или Bilibili требуют авторизованной сессии и применяют изощренный антифрод против стандартных утилит (например, блокируют вызовы обычного `yt-dlp`).
* **Мусорный HTML:** Прямой вызов `curl` возвращает мегабайты рекламных баннеров, обфусцированных JS-скриптов и верстки вместо полезного текстового содержания.
* **Фрагментация инструментов:** Разработчику приходится самостоятельно настраивать, поддерживать и обновлять десяток разрозненных парсеров и MCP-серверов.

**Agent-Reach** объединяет сбор данных из 15+ платформ в единый отказоустойчивый интерфейс командной строки и MCP, не требуя ни копейки за официальные платные API-токены.

## 🔄 3. Архитектура: Отказоустойчивая маршрутизация (Fallback Multi-Backend)

Главная архитектурная особенность Agent-Reach — **многоуровневая маршрутизация бэкендов**:

```text
┌────────────────────────────────────────────────────────┐
│               Agent Reach Core Router                  │
└───────────────────────────┬────────────────────────────┘
                            │
         ┌──────────────────┼──────────────────┐
         ▼                  ▼                  ▼
   ┌───────────┐      ┌───────────┐      ┌───────────┐
   │ Primary   │      │ Secondary │      │ Tertiary  │
   │ Backend   │      │ Fallback  │      │ Browser   │
   └─────┬─────┘      └─────┬─────┘      └─────┬─────┘
         │ (HTTP 403)       │ (OK)             │
         └─────────► Failover ─────────────────┘
```

* Для каждого сервиса определено несколько независимых способов получения данных.
* **Пример из практики:** В июне 2026 года платформа Bilibili заблокировала сигнатуры `yt-dlp`. Вместо аварийного завершения задачи Agent-Reach автоматически переключил внутренний роут на специализированный клиент `bili-cli`. Для AI-агента и пользователя процесс прошел абсолютно бесшовно.
* Если API-маршрут блокируется Cloudflare, подключается локальный headless-контекст `OpenCLI`, использующий существующую авторизованную сессию пользовательского браузера Chrome.

## 🔒 4. Безопасность и локальность данных

> [!NOTE]
> В отличие от облачных скрейпинг-сервисов (BrightData, ScrapingBee), Agent-Reach работает полностью **локально**:

1. **Никакой утечки сессий:** Ваши сессионные куки и токены хранятся исключительно в локальной директории `~/.agent-reach/` и никогда не отправляются на сторонние серверы.
2. **Безопасная работа с браузером:** Утилита не пытается самостоятельно логиниться в сервисы и не читает защищенные хранилища паролей браузера. Она лишь использует уже открытые пользователем сессии через контролируемый Chrome Debugging Protocol.
3. **Встроенный аудит:** Команда `agent-reach doctor` проверяет целостность всех установленных бэкендов, валидность локальных куков и сетевую связность, выдавая готовые рекомендации по исправлению ошибок.

## 🚀 5. Установка и запуск

### Быстрый старт через самого агента (One-Prompt Setup)
Достаточно отправить агенту промпт:
```text
Установи и настрой Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
```
Агент самостоятельно проверит зависимости (Python 3.10+, Node.js, `mcporter`), выполнит установку пакета и запустит проверку окружения.

### Ручная установка через CLI
```bash
# 1. Клонирование и локальная установка
git clone https://github.com/Panniantong/Agent-Reach.git
cd Agent-Reach
pip install -e .

# 2. Диагностика установленных шлюзов
agent-reach doctor

# 3. Примеры чтения контента
agent-reach read "https://x.com/karpathy/status/123456789"
agent-reach youtube "https://www.youtube.com/watch?v=dQw4w9WgXcQ" --subtitles
agent-reach search "LLM inference scaling pure C colibri"
```
