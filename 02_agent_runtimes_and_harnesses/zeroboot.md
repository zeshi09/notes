## 🎯 1. В чем технологический прорыв ZeroBoot?

Главный компромисс изоляции кода агентов всегда был между **скоростью** и **безопасностью**:
* **Языковые песочницы (Monty):** Сверхбыстрые (<1 μs), но не поддерживают произвольные библиотеки из PyPI и системные вызовы.
* **Классические микро-VM (Firecracker, ArcBox):** Максимально безопасны (собственное ядро Linux), но холодный старт занимает 100–300 мс, что создает ощутимую задержку при сотнях мелких вызовов агента.

**ZeroBoot** устраняет этот компромисс:  
Он запускает полноценную изолированную виртуальную машину **менее чем за 1 миллисекунду (<1 ms)** с помощью механизма **Copy-on-Write (CoW) форкинга снимков памяти**:

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        ZEROBOOT SNAPSHOT FORK                          │
│                                                                        │
│   [ Базовый образ ВМ (Python 3.12, Node.js, Linux Kernel) ]            │
│   Загружен заранее в оперативную память в "горячем" состоянии          │
│                                │                                       │
│          ┌─────────────────────┼─────────────────────┐                 │
│          │ CoW Fork (<1ms)     │ CoW Fork (<1ms)     │ CoW Fork (<1ms) │
│          ▼                     ▼                     ▼                 │
│   ┌──────────────┐      ┌──────────────┐      ┌──────────────┐         │
│   │ VM Агента #1 │      │ VM Агента #2 │      │ VM Агента #3 │         │
│   │ Выполняет код│      │ Выполняет код│      │ Выполняет код│         │
│   └──────┬───────┘      └──────┬───────┘      └──────┬───────┘         │
│          │                     │                     │                 │
│          └─────────────────────┼─────────────────────┘                 │
│                                ▼                                       │
│               [ Мгновенный сброс памяти после вызова ]                 │
└────────────────────────────────────────────────────────────────────────┘
```

## 💎 2. Ключевые преимущества

1. **Суб-миллисекундный старт (<1 ms):** Вызов изолированной виртуальной машины ощущается моделью как мгновенный вызов локальной функции.
2. **Полная изоляция на уровне железа (Hardware-level KVM):** Даже если сгенерированный LLM код попытается скомпрометировать память процесса или выполнить kernel exploit, он заперт внутри виртуального процессора vCPU.
3. **Эфемерный диск и память:** Каждая виртуальная машина работает в режиме изоляции снимка: изменения пишутся в приватную delta-память и уничтожаются при выходе.
4. **Чистый Rust:** Нулевые накладные расходы рантайма, отсутствие сборщика мусора и минимальное потребление RAM в ожидании.

## 🚀 3. Быстрый запуск

```bash
# Клонирование и сборка на Linux c поддержкой KVM (/dev/kvm)
git clone https://github.com/zerobootdev/zeroboot.git
cd zeroboot
cargo build --release

# Запуск демо-песочницы
./target/release/zeroboot-daemon --base-image python:3.12-slim
```
