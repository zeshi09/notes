## 🎯 1. В чем главная проблема поиска в AI-агентах?

Когда терминальный агент (Claude Code, Codex, Antigravity) исследует большой проект:
* **Обычный `grep` / `ripgrep`:** Требует точного совпадения подстроки. Если разработчик назвал функцию `calculate_tax()`, а агент ищет `compute_vat()`, `ripgrep` вернет пустоту.
* **Облачный RAG:** Требует отправки всех файлов в облако, платных API эмбеддингов, страдает от задержек сети и несет риски утечки приватного кода.

**zvec-grep (`zg`)** — это **локальный гибридный поисковый слой** нового поколения:
Он совмещает классический поиск по ключевым словам (BM25) и плотные векторные эмбеддинги, работая **на 100% локально на вашей машине**.

```text
┌────────────────────────────────────────────────────────────────────────┐
│                          ZVEC-GREP (zg) PIPELINE                       │
│                                                                        │
│   1. Запрос пользователя / агента: "где обрабатывается авторизация?"    │
│                                                                        │
│   2. Параллельный локальный поиск:                                     │
│      ├── BM25 Exact Match (по ключевым токенам: auth, jwt, login)      │
│      └── Локальные эмбеддинги (семантическое понимание смысла)         │
│                                                                        │
│   3. Реранкинг (Reciprocal Rank Fusion):                               │
│      Слияние результатов и отсечение мусора                            │
│                                                                        │
│   4. Агентный компактный вывод:                                        │
│      Выдает структурированный Markdown/JSON с точными строками         │
│      [auth_service.py: L45-L72] без забивания контекста модели        │
└────────────────────────────────────────────────────────────────────────┘
```

## 💎 2. Ключевые возможности

1. **Local-First & Нулевая телеметрия:** Все вычисления, эмбеддинги и векторные индексы строятся локально на CPU/GPU без отправки байта данных наружу.
2. **Сверхбыстрая индексация (zvec engine):** Векторное ядро на C++/Rust индексирует репозитории на десятки тысяч файлов за считанные секунды.
3. **Режимы вывода для людей и AI:**
   * Интерактивный TUI-режим для разработчика в терминале.
   * Компактный JSON/Markdown режим для встраивания в агентные пайплайны.
4. **Инкрементальный переиндекс:** Следит за файловой системой и мгновенно обновляет только измененные файлы.

## 🚀 3. Быстрый запуск

```bash
# Установка через npm (требуется Node.js >= 22)
npm install -g @zvec/zvec-grep

# Семантический поиск по текущей кодовой базе
zg "jwt validation logic"

# Вывод в формате JSON для AI-агентов
zg "database migration scripts" --json
```
